# Değerlendirme kanıtları

Kaggle gönderimi yapıldıktan sonra skor ekran görüntülerini bu klasöre ekleyin.
Her gönderim için tarih, kullanılan model, public/private skor ve ilgili commit bilgisini belirtin.

Henüz skor ekran görüntüsü eklenmedi. Yerel doğrulama sonuçları resmi Kaggle skoru olarak sunulmamalıdır.
